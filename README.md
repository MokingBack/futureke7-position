# 交易可查网-持仓观察 历史数据（2026年）

## 数据来源
用户提供的53张历史截图（覆盖 2026-01-09 至 2026-10-30，共 53 个交易日），人工转录为结构化 JSON。

## 文件清单
- `position_raw_2026.json` — 全量三栏（五大家人/五大机构/外资）逐日操作明细
- `rb_hc_timeline.csv` — 螺纹钢(RB)+热卷(HC)专项时间线，共 43 条记录

## 关键发现（针对 RB 复刻/交易）

### 1. 五大家人（散户）在 RB 上全程零出现
53 个交易日里，"五大家人"栏从未列过螺纹钢/热卷。
→ 反推：**散户在 RB 上没有形成逆势扛单的大群体**，所以蓝图的"散户反向"筛选器没把 RB 捞出来。
→ 复刻产品时：当某品种散户席位持仓变动不显著，蓝图该栏就不会列它。

### 2. 机构在 RB 上动作稀疏，呈波段性
- 1/09 减多 → 1/29 加多 → 1/30 减多（1月底试多被埋）
- 2/24 加空 → 2/25 加多（反手很快，日内级别）
- 3/06–3/17 连续加多（这一段是机构+外资合力做多的主升浪窗口）

### 3. 外资在 RB/HC 上的节奏最值得跟
- 1/16 加多 → 2/05 反手加空 → 2/25 减空
- **3/06–3/17 连续 7 个交易日加多 RB**（这是蓝图里非常少见的连续同向动作，事后看是一波大行情）
- 4/07 减多 → 4/09 加空（4月初翻空）
- **10/08–10/30 连续加空/做空 RB+HC，且 10/27 从"加空"升级为"做空"**（最新一段，外资对黑色系持续施压）

### 4. 复刻要点
- 三栏不是客户级拆分，是期货公司席位的标签分组
- 每天"列哪些品种"= 变动阈值筛选（推测约 500–1000 手以上变动才上榜）
- 同一品种一天可能在多栏出现，方向经常相反（这就是"围猎"叙事的数据基础）

## 注意
- OCR 转录可能存在个别错字，关键决策前请对照原图
- "加空/做空"区别：加空=空单加仓；做空=从平多翻空或新方向；"减空"=平空；"减多"=平多
